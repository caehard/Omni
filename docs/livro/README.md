## Referência rápida

| Conceito | Regra |
|---|---|
| Dados rolados | **Atributo + 1** dados |
| Tipo de dado | pelo nível do Domínio: −1 → d100 · 0 → d20 · 1 → d12 · 2 → d10 · 3 → d8 · 4 → d6 · 5 → d4 · 6 → d2 |
| Sucesso | dado **≤ ND** · resultado natural **1** = crítico (sempre sucesso) |
| Teste | sucessos ≥ **NS** → passou |
| Disputa | mais sucessos vence; a diferença indica a margem |
| Maestria(N) | reduz valores de dados, somando no máximo N (reduzido a 1 não é crítico) |
| Vantagem/Desvantagem(N) | ± N sucessos |
| Vida | 1 + Resiliência + 2 × Vitalidade |
| Sanidade | Atributo de Determinação (Raciocínio ou Instinto) + 1 |
| Pontos de Tempo | 1 + Ritmo + Resiliência (+ até 3 Pontos Críticos) |
| Custo de ação | nº de ações já feitas na rodada + 1 + extras |
| Evasão | 7 − Fortitude |
| Resistência Geral / Mental | 1 + 2 + … + nível de Resiliência / Mental |
| Pontos Especiais | 1 + Reserva |
| Pontos de Conjuração | nível de Controle |
| Slots | Força + 5 |
| Pontos Heroicos | 2 × nível do personagem |
